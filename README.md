# Idempotent Transaction Processor

## Overview

A Java-based background transaction processing service designed to handle duplicate requests, out-of-order transactions, and retryable failures.

## Features

Transaction validation
Idempotent processing
Duplicate detection
Sequence-based transaction handling
Retry and failure handling
Processing status reporting
Automated unit tests

## Technology Stack

Java
Gradle
JUnit 5

Implementation in progress.
